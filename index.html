What is a LitBuy spreadsheet?

A LitBuy spreadsheet is a research list for keeping product finds, seller links, selected options and order notes together. It can be a conventional sheet or a searchable catalogue.

This page pairs a practical shopping checklist with a small, dated import from the HipobuyFind homepage. Use it to discover products and build a shortlist; confirm the original seller link and whether your chosen agent supports it before ordering.

Keep these details for every find

Product name · listing ID · original seller URL · selected colour · size measurements · option price · quantity · warehouse photos · parcel estimate.

A working catalogue entry does not establish authenticity, current stock, seller reliability or compatibility with any agent. None of the imported products is marked as independently QC-verified.

How to use this LitBuy spreadsheet guide

  1. Find the right category.Search product names or filter the snapshot. Save the listing ID so similar photos do not get mixed up.
  2. Open HipobuyFind and locate the item.Compare the current source listing with the recorded name and ID. Check which option the displayed price actually buys.
  3. Record the original seller link.If you plan to order through LitBuy, check that the original marketplace URL opens correctly in your account. This page does not convert or verify agent links.
  4. Confirm size and construction.Compare garment measurements with something you own. For shoes, check the size chart and selected colourway rather than relying only on a size label.
  5. Review the order and parcel separately.Confirm item cost first, then review warehouse photos, packed dimensions, available shipping routes and the final payable total.

Before international shipping

A practical QC checklist

  • Match the order: confirm the listing ID, selected colour, size label and number of pieces.
  • Request useful views: front, back, close-ups and measurements where needed. A seller photo is not a photo of your order.
  • Inspect the construction: look for uneven stitching, stains, damaged fasteners, sole separation or missing parts.
  • Resolve differences early: record the issue and check the applicable return conditions before approving shipment.
  • Check the packed parcel: dimensions and packaging can change shipping costs. Compare the actual quote for your destination.

QC helps document visible condition and order accuracy. It does not certify authenticity or predict long-term durability.

LitBuy spreadsheet FAQ

What is a LitBuy spreadsheet?

A LitBuy spreadsheet is a product research list used to organize finds, source links, selected variants and order notes. This independent page combines a buying guide with catalogue references imported from HipobuyFind.

Where do the shopping buttons go?

The LitBuy spreadsheet and Buy it now buttons both open HipobuyFind. They do not open LitBuy checkout or place an order.

Are the displayed prices final delivered prices?

No. Displayed CNY prices are a source catalogue snapshot recorded on 19 November 2026. Options, stock, shipping, service fees and taxes must be checked separately.

Are listing images QC photos?

No. The images shown here are source catalogue images. Warehouse QC photos should match the exact listing and selected size and colour before shipping.

Can I download a spreadsheet?

Save products from the catalogue and use Export shortlist CSV. The file contains the selected names, categories, item IDs, recorded CNY prices, source reference URLs and snapshot date. It is a research export, not an order form.

Can these products be ordered through LitBuy?

Compatibility has not been verified. Obtain the original marketplace link from the source listing, check it in your chosen agent account and confirm the exact option, restrictions and current price before paying.
